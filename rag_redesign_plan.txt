# AI Storyboard Generator - RAG Architecture Redesign Plan
# ==========================================================

## Executive Summary

This plan outlines a complete redesign of the current storyboard generation system, moving from a chronological sliding window approach to a semantic retrieval system with proper memory tiers. The new architecture emphasizes:

1. **Semantic Memory Retrieval**: Replace sliding window with similarity-based retrieval using scene embeddings and entity overlap
2. **Leaner Agent Architecture**: Consolidate from 3 agents to 3 specialized components (Planner, Renderer, Vision QA)
3. **Structured Memory Model**: Implement Canonical, Episodic, and Working memory tiers
4. **Token Efficiency**: Reduce prompt size by 50-70% through smart retrieval and structured data
5. **Parametric RAG Model**: Maintain flexibility in retrieval parameters and strategies

## 1. Memory Model Architecture

### 1.1 Three-Tier Memory System

```
┌─────────────────────────────────────────────────────────────────┐
│                         MEMORY TIERS                            │
├─────────────────────────────────────────────────────────────────┤
│ CANONICAL MEMORY (Static, Never in Prompts)                    │
│ ├── style.md (artistic guidelines)                             │
│ ├── entities.md (character/object descriptions)                │
│ ├── script.md (full narrative)                                 │
│ └── appearance_vectors/ (per-entity visual embeddings)         │
├─────────────────────────────────────────────────────────────────┤
│ EPISODIC MEMORY (Append-Only Scene Summaries)                  │
│ └── scene_memories/                                            │
│     └── {scene_id}.json                                        │
│         ├── scene_id: int                                      │
│         ├── shot_description: str                              │
│         ├── entities_present: List[str]                        │
│         ├── entity_states: Dict[str, EntityState]              │
│         ├── camera_spec: CameraSpec                            │
│         ├── visual_elements: List[str]                         │
│         ├── embedding: List[float] (1536-dim)                  │
│         ├── generated_images: List[ImageRef]                   │
│         └── critic_tags: List[str]                             │
├─────────────────────────────────────────────────────────────────┤
│ WORKING MEMORY (Dynamic, Retrieved for Each Scene)             │
│ └── Top-K relevant episodic memories based on:                 │
│     ├── Semantic similarity (cosine distance)                  │
│     ├── Entity overlap score                                   │
│     └── Narrative distance penalty                             │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 Retrieval Strategy

```python
def retrieve_relevant_memories(current_scene, k=5):
    """
    Parametric retrieval function combining:
    1. Semantic similarity (0.6 weight)
    2. Entity overlap (0.3 weight)
    3. Narrative distance penalty (0.1 weight)
    """
    scores = []
    for memory in episodic_memories:
        # Semantic similarity using embeddings
        semantic_sim = cosine_similarity(
            current_scene.embedding, 
            memory.embedding
        )
        
        # Entity overlap score
        current_entities = set(current_scene.entities)
        memory_entities = set(memory.entities_present)
        entity_overlap = len(current_entities & memory_entities) / 
                        len(current_entities | memory_entities)
        
        # Narrative distance penalty (prefer recent relevant scenes)
        distance = abs(current_scene.id - memory.scene_id)
        distance_penalty = 1 / (1 + distance * 0.01)
        
        # Combined score (parametric weights)
        score = (semantic_sim * 0.6 + 
                entity_overlap * 0.3 + 
                distance_penalty * 0.1)
        
        scores.append((memory, score))
    
    return sorted(scores, key=lambda x: x[1], reverse=True)[:k]
```

## 2. Agent Architecture Redesign

### 2.1 Planner Agent (Replaces Director + Part of Artist)

**Responsibilities:**
- Parse next scene from script
- Detect entities using canonical memory
- Retrieve relevant episodic memories
- Generate structured scene plan

**Input Schema:**
```json
{
  "scene_id": 42,
  "raw_description": "Helena crouches behind debris...",
  "canonical_context": {
    "style_guide": "style.md excerpt",
    "entity_descriptions": ["Helena", "Silicate Army"]
  }
}
```

**Output Schema:**
```json
{
  "scene_id": 42,
  "entities": [
    {
      "name": "Helena",
      "canonical_id": "CHAR_HELENA",
      "pose": "crouching behind debris",
      "emotion": "determined, alert",
      "visual_ref_ids": ["helena_ref_01", "helena_ref_03"]
    }
  ],
  "camera": {
    "type": "medium shot",
    "angle": "eye level",
    "movement": "slow push in"
  },
  "environment": {
    "setting": "destroyed urban street",
    "lighting": "harsh shadows, fire glow",
    "mood": "tense, apocalyptic"
  },
  "visual_beats": [
    "explosion illuminates background",
    "debris particles in air"
  ],
  "retrieved_context": [
    {"scene_id": 38, "relevance": 0.89},
    {"scene_id": 15, "relevance": 0.76}
  ]
}
```

### 2.2 Renderer Agent (Simplified Artist)

**Responsibilities:**
- Expand canonical placeholders
- Inject appearance vectors
- Generate image using GPT-4o vision
- Apply style consistency techniques

**Prompt Template:**
```
[SYSTEM]
You are generating storyboard frame {scene_id} in {style_name} style.

[CANONICAL APPEARANCE]
{expanded_entity_descriptions}

[SCENE PLAN]
{scene_plan_json}

[VISUAL CONTEXT]
{retrieved_episodic_images}

[INSTRUCTION]
Generate a single storyboard frame that:
1. Matches the exact scene plan specifications
2. Maintains character consistency using provided references
3. Follows the established visual style
4. Integrates naturally with the visual context provided
```

### 2.3 Vision QA Agent (Enhanced Critic)

**Responsibilities:**
- Analyze generated image against scene plan
- Check style consistency
- Verify entity accuracy
- Provide structured feedback

**Output Schema:**
```json
{
  "status": "pass|fail",
  "scores": {
    "composition_match": 0.85,
    "style_adherence": 0.92,
    "entity_accuracy": 0.78,
    "narrative_coherence": 0.88
  },
  "issues": [
    {
      "type": "entity_deviation",
      "entity": "Helena",
      "description": "Hair color inconsistent with reference"
    }
  ],
  "retry_guidance": "Emphasize Helena's dark hair as shown in references"
}
```

### Phase 3: Semantic Retrieval System (Week 3)

1. **Implement embedding generation:**
   ```python
   class EmbeddingService:
       def __init__(self):
           self.model = "text-embedding-3-small"
           
       def embed_scene(self, scene: SceneDescription):
           # Combine description, entities, visual elements
           text = f"{scene.description} {' '.join(scene.entities)}"
           return openai.embeddings.create(
               input=text,
               model=self.model
           ).data[0].embedding
   ```

2. **Build retrieval pipeline:**
   ```python
   class SemanticRetriever:
       def __init__(self, memory_service: MemoryService):
           self.memory = memory_service
           
       def retrieve(self, query: ScenePlan, params: RetrievalParams):
           # Implement parametric retrieval
           # Allow customization of:
           # - k (number of memories)
           # - weights (semantic vs entity vs distance)
           # - entity_boost (specific character importance)
           # - time_decay (how much to penalize old memories)
           return self.memory.episodic.search(
               query_embedding=query.embedding,
               filter_entities=query.entities,
               limit=params.k,
               metric=params.metric
           )
   ```

### 4.2 Compatibility Layer

```python
class BackwardCompatibleCLI:
    """Maintains CLI interface while using new architecture"""
    
    def __init__(self):
        self.legacy_params = {
            '--context-window': self.convert_to_retrieval_k,
            '--variations': 'variations',
            '--max-retries': 'max_retries'
        }
    
    def convert_to_retrieval_k(self, window_size: int):
        # Map sliding window size to retrieval K
        if window_size == 0:
            return 0  # No retrieval
        elif window_size == -1:
            return 50  # Large K for "all" context
        else:
            return min(window_size, 10)  # Reasonable K
```

- **New**: Constant time per shot
- **Method**: Fixed retrieval K + efficient embeddings

### 6.4 Flexibility
- **Current**: Fixed sliding window
- **New**: Parametric retrieval with multiple strategies
- **Method**: Configurable weights and thresholds
